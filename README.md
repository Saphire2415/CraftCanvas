# CraftCanvas Studio
### The Ultimate Texture Forge for Minecraft



---

## 🎨 Overview
**CraftCanvas Studio** is a powerful, web-based texture editing tool designed for Minecraft creators. Edit your block and item textures directly in your browser with real-time previewing and seamless resource pack compilation.

![Title Logo](pack.png)

---

## 🛠 Features
* **Real-time Editing:** Modify textures and see updates instantly.
* **Auto-Compile:** Export your work as a ready-to-use `.zip` resource pack.
* **Responsive Design:** Works on desktop and mobile browsers.
* **Asset Manager:** Built-in drawer to handle all your Minecraft sprites.

## 📦 How to Use
1. Clone this repository.
2. Open `index.html` in your web browser.
3. Click **Load Resource Pack** to upload your existing files.
4. Start forging!
